# blockvase.com

Public frontend for [blockvase.com](https://blockvase.com).

This repository is the hosted site: HTML, CSS, JavaScript, media, and the product model.

No license has been published yet.

## Run locally

Serve the repo root with any static file server, then open the site in a browser. Viewer and pool data come from `/api/` on the production host, so those tabs need a proxy or https://blockvase.com/.

## Pull requests

Open PRs against `main`.
